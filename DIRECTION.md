structure, 3D kitchen build, finish picker, quote form, progress rail, section labels
and mobile call bar all kept. Header + call-bar code kept exactly (see LESSONS.md).

## 1. Three reference sites (named from memory — no verification trips)
1. **deVOL Kitchens** (devolkitchens.co.uk) — borrowing: editorial calm, a serif-led
   heading over lots of quiet space, nothing shouting.
2. **Studio McGee** (studio-mcgee.com) — borrowing: a warm-neutral base carried by a
   single metallic accent, used sparingly.
3. **Pinch** (pinchdesign.com) — borrowing: high-contrast Didone display set against a
   plain grotesque body.

## 2. What it feels like (one sentence, no borrowed adjectives)
A Lucknow drawing-room at dusk: limewash walls, one marigold-gold line, and the hush of
a cusped Nawabi arch over the doorways.

## 3. Type + palette
- **Display:** Bodoni Moda (high-contrast Didone). Not Inter/Roboto/Arial/Helvetica/
  Open Sans/Montserrat/Poppins/Playfair/system-ui. Differs from every sibling
  (Gloock, Rozha One, Young Serif, Marcellus, Instrument Serif, Zilla Slab, Hepta Slab,
  Bricolage, Fraunces).
- **Body:** Albert Sans (grotesque). Differs from every sibling body
  (Schibsted Grotesk, Mukta, Karla, Figtree, Hanken Grotesk, Mulish, Hind, Spline Sans,
  Instrument Sans).
- **Devanagari (brand line only):** Tiro Devanagari Hindi (Lucknow = Hindi).
- **Five hex (all new, differ from LESSONS three + every sibling):**
  - `--limewash #EDE6D6` — page background
  - `--ink      #231C2A` — aubergine-ink text + dark sections
  - `--plum     #4A2238` — deep Mughal plum, the reviews feature block
  - `--marigold #D08A1F` — marigold gold, the one accent (actions, seams, rail)
  - `--jade     #2E5E52` — muted jade, the secondary block
  - support: `--muted #5E5349`, `--line #D6CBB4`, `--paper #F6F0E3`

## 4. Signature move
The one animated moment stays the **scroll-driven kitchen build** — an L-shaped modular
kitchen assembles into an empty room as you scroll, step list and progress rail advancing
off the same value, nothing else moving.
**Static motif (new):** a cusped **Nawabi arch** scallop runs along each section's top
edge (replacing the reeded-flute seam), in that section's own colour; the accent strip is
the same scallop in marigold. Differs from plywood-edge (Bhumi), LED-strip (Mangesh),
chevron-seam (Harsiddhi) and reeded-flute (Trendy Space).

## 5. Headline (new)
**"Your whole flat, designed down to the last handle."**
(`<em>` break on "designed down to the last handle.") Differs from every sibling headline.
